RISA Barcode Label System

Aplikasi cetak barcode cepat berbasis data catalog produk.

🔍 Verifikasi Scanner 📊 Pendataan Outbound
💡 Panduan Cetak Printer Label:
  1. Sesuaikan Margin Kertas, Jarak Kolom, Jarak Baris, dan Tinggi Label di sidebar kiri agar pas dengan kertas stiker Anda.
  2. Klik tombol "Cetak Label Terpilih" di sidebar kiri.
  3. Pada dialog print browser yang muncul, atur Margin = "None" (Tanpa Margin).
  4. Pastikan untuk mengaktifkan opsi "Background graphics" (Grafik Latar Belakang) agar format cetak ter-render sempurna.
  5. Matikan opsi "Headers and footers" (Header dan footer) agar tidak ada teks URL/tanggal tercetak di margin atas-bawah kertas.
